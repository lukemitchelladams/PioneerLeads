## Accessible PDF checklist (WCAG 2.1 AA, RFP §4.1.B)

For every file before it goes to Luke:
1. Build in Word or LibreOffice with real styles: Title, Heading 1-3, lists, tables with a marked header row (repeat on each page).
   No layout by spaces or tabs, no text in images.
2. Document properties: Title = "Brown Bison Holdings LLC, RTD RFP 126DM016, [file name]"; language English (United States).
3. Alt text on every image (org charts: use each firm's text list in RESPONSE-DRAFT Part 3.B; logo: "Brown Bison Holdings LLC logo").
   Meaning never by color alone; text contrast at least 4.5:1 (black on white).
4. Export as tagged PDF (Word: "Document structure tags for accessibility" and "Create bookmarks using Headings"; LibreOffice:
   "Universal Accessibility (PDF/UA)" and "Export outlines"). Check the PDF has a structure tree, the language and the title set to
   display (HQ checks with pypdf: /StructTreeRoot, /Lang, /MarkInfo).
5. RTD's own forms (SBE Enclosures are tagged but have no fill-in fields; the W-9 and Key Personnel forms are not in hand): type
   into them, do not scan them. Sign electronically where accepted so the page stays text. A wet-ink or notarized page that must be
   scanned gets OCR and a short alt-text description ("Enclosure 1A, SBE Affidavit, signed by Luke Adams and notarized on
   [date]"). Whether RTD accepts e-signatures and remote notarization is not stated in RFP.
6. Pricing Sheet: export the filled .xlsx to PDF with headers intact; keep sheet names and cell text readable; no merged-cell
   tricks added.
7. File names without spaces; nothing password-protected (RTD must open and tag-check it).
