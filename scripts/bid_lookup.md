# Where to find Town of Parker solicitations

Town of Parker, CO posts ALL solicitations on the Rocky Mountain E-Purchasing System, which is
BidNet Direct's Colorado purchasing group.

1. https://www.bidnetdirect.com/colorado/town-of-parker  (log in; register free if needed)
2. Open the HVAC On-Call solicitation → download the full document set + addenda.
3. Town mirror: https://www.parkerco.gov/207/Current-Projects-Out-For-Bid
4. Can't find it? Call Town Procurement 303-805-3188 and ask for the buyer on the HVAC on-call bid.
   RMEPS vendor support: 800-835-4603.

## Federal (SAM.gov)
Town of Parker is local, so it will NOT be on SAM.gov. Use `scripts/samgov_search.py` only for
federal HVAC/chiller opportunities (e.g., Buckley SFB, VA Eastern Colorado, GSA Region 8).
